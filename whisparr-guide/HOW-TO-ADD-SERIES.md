## 🚀 كيفية الاستخدام:

### **الطريقة الأولى: استخدام Python** (الأفضل)

1. **تثبيت Python:**
   ```cmd
   # تحميل من python.org
   # أو في Windows:
   winget install Python.Python.3.11
   ```

2. **تثبيت المكتبات:**
   ```cmd
   pip install requests
   ```

3. **الحصول على API Key:**
   - اذهب إلى Whisparr
   - Settings → General
   - انسخ "API Key"

4. **تعديل السكريبت:**
   ```python
   WHISPARR_URL = "http://localhost:6969"
   API_KEY = "your-api-key-here"  # استبدل هنا
   ```

5. **تشغيل السكريبت:**
   ```cmd
   python add-series-auto.py
   ```

6. **الانتظار:**
   - سيضيف المسلسلات تلقائياً
   - ستجد تقرير في `whisparr_results.json`

---

### **الطريقة الثانية: استخدام Batch**

1. **تشغيل الملف:**
   ```cmd
   add-series-auto.bat
   ```

2. **إدخال API Key:**
   - سيطلب منك API Key
   - أدخله وستبدأ الإضافة

3. **الانتظار حتى تنتهي**

---

### **الطريقة الثالثة: الإضافة اليدوية**

1. **افتح Whisparr:**
   ```
   http://localhost:6969
   ```

2. **اضغط على:
   ```
   + Add Series
   ```

3. **ابحث عن المسلسل:**
   - اكتب اسم المسلسل
   - اختر النتيجة
   - اضغط Add

4. **كرر للمسلسلات الأخرى**
